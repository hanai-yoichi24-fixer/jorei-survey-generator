# 条例調査表ジェネレーター（屋外広告物）

物件情報と看板リストから、屋外広告物申請の**条例調査表ドラフト**を自動生成する静的Webアプリ。

## 何をするか
- 住所・用途地域・建物高さなどの物件情報と、看板（種別・壁面・寸法・数量）を入力
- 東京都屋外広告物のしおり（2025）／新宿区景観まちづくり条例の手引き（R5）の規制値に照らして判定
- 管轄（都条例＝許可区域／区の景観条例＝事前協議／道路占用）を分岐
- 面積を自動計算し、壁面ごとの3/10基準・総量規制・適用除外(10㎡)と突合
- 「適合／要確認／要是正」で判定した条例調査表＋面積計算表を出力（印刷・PDF保存可）

## 設計上のポイント
- **完全クライアントサイド**：入力データはブラウザ内でのみ処理し、サーバーへ送信・保存しない（社外秘データ配慮）。
- **「要確認」は人的判断に残す**：道路占用・越境・離隔など公開文書で決まらない箇所は自動確定しない。
- 規制値は `index.html` 内の `KB` オブジェクトに集約。条例更新時はここを直す。

## 技術構成
- 単一の静的HTML（フレームワークなし）。ビルド不要。
- ホスティング：Vercel（静的配信）。

## 既知の制約（叩き台段階）
- 対応は東京都（新宿区）ベース。自治体差分（しおり相当文書の名称・構成・粒度の違い、非オンライン自治体）は未対応。
- 壁面基準面積は代表値の内部既定。実務では現地実測値に置き換える。
- 判定はドラフト。最終確認は各法令・行政窓口で行う。
